## 완성 코드

def judge\_price\_status(change\_rate):

    if change\_rate \>= 5:

        return "급등 (투자에 주의하세요\!)"

    elif change\_rate \>= 1:

        return "상승"

    elif change\_rate \== 0:

        return "보합"

    elif change\_rate \<= \-5:

        return "급락 (투자에 주의하세요\!)"

    return "하락"

\# 입력

coin\_name \= input("암호화폐 이름을 입력하세요: ")

current\_price\_text \= input("현재 가격을 입력하세요: ")

change\_rate\_text \= input("등락률을 정수로 입력하세요: ")

\# 처리

current\_price \= int(current\_price\_text)

change\_rate \= int(change\_rate\_text)

status \= judge\_price\_status(change\_rate)

\# 출력

print(f"{coin\_name} 현재 가격: {current\_price}원")

print(f"등락률: {change\_rate}%")

print(f"가격 상태: {status}")

## 디버깅 기록 — 여기까지 오면서 에러 일곱 개를 잡았다

완성 코드만 보면 순탄해 보이지만, 사실 에러를 일곱 개 만났다. 잊어버리기 전에 기록해 둔다.

### 워밍업: TODO 단계에서 두 개

TODO 1·2에서 `current_price = int(input(current_price_text))`라고 썼다. 이미 입력받아 둔 값을 놔두고 `input()`을 또 불러서, 같은 값을 두 번 입력해야 하는 프로그램이 됐다. 필요한 건 입력이 아니라 **변환**이었다: `int(current_price_text)`.

TODO 3에서는 함수 정의 전체를 따옴표 안에 통째로 붙여넣는 실수를 했다. 함수는 정의를 복사하는 게 아니라 **이름을 불러야** 실행된다. `status = judge_price_status(change_rate)`.

### 1\. NameError — 매개변수는 함수 안의 이름표였다

표준·확장 과제를 하면서 함수를 고치다가 만난 에러. 오늘의 가장 큰 깨달음이 여기 있다.

status\_A \= judge\_price\_status(change\_rate\_A)

                              ^^^^^^^^^^^^^

NameError: name 'change\_rate\_A' is not defined. Did you mean: 'change\_rate'?

**매개변수는 함수 안에서만 쓰는 자리 이름표**다. `def judge_price_status(change_rate_A, ...)`라고 썼다고 해서 함수 밖 세상에 `change_rate_A`라는 변수가 생기는 게 아니었다. 호출할 때는 내가 **실제로 갖고 있는 변수**를 괄호에 넣어야 한다. 내가 가진 건 입력받아 정수로 변환해 둔 `change_rate` 하나뿐이었다.

심지어 파이썬이 마지막 줄에서 힌트까지 주고 있었다. *"Did you mean: 'change\_rate'?"* — 에러 메시지는 마지막 줄부터 읽으라던 말이 실감 났다.

### 2\. 매개변수 이름과 몸통이 따로 놀고 있었다

함수 첫 줄은 `change_rate_A`, `change_rate_B` 두 개를 받는다고 선언했는데, 정작 몸통은 `change_rate`라는 이름을 쓰고 있었다. 이 함수에 필요한 입력은 등락률 하나뿐이니까, 매개변수도 하나로 줄이고 몸통과 같은 이름으로 통일했다. 호출도 두 번이 아니라 한 번이면 된다.

### 3\. return은 값 하나만

급등·급락일 때 경고 문구도 같이 돌려주고 싶어서 이렇게 썼었다.

return "급등", "투자에 주의하세요\!"   \# → ('급등', '투자에 주의하세요\!') 로 출력됨

return "급락""투자에 주의하세요"      \# → 급락투자에 주의하세요 (붙어버림)

첫 번째는 값 두 개가 괄호 묶음째 출력되고, 두 번째는 에러도 없이 두 문자열이 한 덩어리로 붙어 버린다. 지금 배운 범위에서 답은 하나 — 전하고 싶은 말이 있으면 **문자열 하나로 합쳐서** 돌려주면 된다. 이게 확장 과제(주의 문구 출력)의 해결책이 됐다.

### 4\. '하락'과 '급락'이 뒤바뀌어 있었다

에러는 안 나는데 결과가 이상한, 제일 무서운 종류의 버그. `-7`을 넣고 조건을 손으로 따라가 봤다.

`>= 5` ✗ → `>= 1` ✗ → `== 0` ✗ → `<= -5` ✓ → **"하락"**

폭락했는데 하락이란다. 반대로 `-2`는 조건 네 개를 전부 통과하지 못해 마지막 줄의 "급락"에 도착한다. 음수 쪽도 극단 기준(`<= -5`)이 "급락"이 되도록 라벨을 맞바꿨다. 조건문은 위에서부터 검사하니까, 범위가 겹치면 극단 기준을 먼저 써야 한다.

### 5\. 이름을 바꿨으면 끝까지 바꿔야 한다

변수를 `status_A`, `status_B`로 바꿔 놓고 마지막 print에는 `{status}`를 쓰고 있었다. 또 NameError. 변수 이름은 철자 하나까지 정확히 일치해야 한다. 하나로 통일해서 해결.

| 입력한 등락률 | 예상 상태 | 실제 상태 | 일치 여부 |
| :---- | :---- | :---- | :---- |
| 5 | 급등 | 급등 (투자에 주의하세요\!) | 일치 |
| 4 | 상승 | 상승 | 일치 |
| 1 | 상승 | 상승 | 일치 |
| 0 | 보합 | 보합 | 일치 |
| \-1 | 하락 | 하락 | 일치 |
| \-4 | 하락 | 하락 | 일치 |
| \-5 | 급락 | 급락 (투자에 주의하세요\!) | 일치 |
| \-7 | 급락 | 급락 (투자에 주의하세요\!) | 일치 |

`5`와 `-5`를 꼭 넣어야 하는 이유: 기준과 정확히 같은 값이 포함되는지(`>=`, `<=`)는 경계에서만 드러나기 때문이다.

  변수가 존재하지 않아 NameError가 났기 때문.

입력·처리·출력 중 해당하는 부분: 처리

어떻게 확인했는지: 경계값 8개(5, 4, 1, 0, \-1, \-4, \-5, \-7)를 넣어 예상 상태를 먼저 적고

  실제 출력과 비교했다. AI가 짚어 준 수정도 그대로 믿지 않고 이 테스트로 직접 검증했다.

## 오늘 배운 것

- 매개변수는 함수 안에서만 쓰는 이름표다. 호출할 때는 내가 가진 실제 변수를 넣는다.  
- `return`이 돌려주는 값은 하나다. 전할 말이 있으면 문자열로 합친다.  
- 범위가 겹치는 조건은 극단 기준부터 검사하고, 경계값으로 검증한다.  
- 에러 메시지는 마지막 줄부터 읽는다. 파이썬은 생각보다 친절하다.
